## 查出了什么

1. **诊断体系和编码混用。** 有些代码指向的含义比节点名称更窄，还有把不同疾病/发作或医学状态当作同义词赋码的情况。候选处理保留具体分类体系、版本和适用条件，不猜一个“通用替代码”。
2. **诊断条件过度简化。** 抑郁发作与抑郁障碍混用，核心/附加症状固定计数、严重程度、病程时限以及物质/躯体疾病排除规则均有需要修订的条目。因果归因排除不能简化为存在某共病就排除诊断。
3. **关系方向及图谱角色不准确。** 部分父领域指向子例子的`SUBTYPE_OF`方向反了；病程修饰信息、疾病亚型、症状领域和综合征也有混用。修订方案说明采用何种关系或为何需分开建模。
4. **治疗顺序省略前提。** 一线/二线、增效及维持方案需考虑疾病阶段、严重程度、既往足量足疗程、耐受性、偏好及专科复核。类别推荐不能自动成为所有成员药物的同等疗效证据。
5. **用药规则缺范围。** 剂量、血药范围、清洗期和禁忌需要绑定具体药物、方向、地区、制剂与人群。体外结果不能升级为临床“没有相互作用”，类别警示不能伪装成每一具体药对已证实的效应。
6. **研究性程序被写得过于常规。** 对照所列NICE指南后，DBS和rTMS的OCD条目补充了研究情境等限制；这不用于替代其他地区、设备和适应症的具体许可判断。

以上是软件数据审计的发现分类。具体医学主张、页码、版本和限制见逐项台账，不能直接作为个人诊疗或用药方案。

## 来源与检查边界

来源目录共50项：49项已取得本地原文，46项实际用于证据；每份实际使用的原文均绑定SHA256，并保存PDF物理页码或原始HTML锚点。来源包括WHO诊断手册及ICD-10分类、WHO ATC分类、NICE指南、中国具体产品说明书、美国DailyMed标签和英国产品SmPC。

没有把下载成功当作核实通过：旧GSK拉莫三嗪地址获取失败的记录仍保留，另取得不同来源的美国拉莫三嗪标签并按该产品单独使用。一个NICE编号地址实际属于无关主题，已明确排除，未用于任何OCD结论，另查得正确的DBS指南。

中国说明书、美国标签、英国指南/SmPC和WHO诊断分类分别保留地区、产品及版本。跨来源比较时分别链接两份原文，不静默选择一方，也不把研究对象出现在安全汇总中视为该产品批准适应症。

本轮“全部核对”指对固定清单逐项完成**所列可得原文范围内的比较与处理**，不表示穷尽所有文献、所有中国产品说明书，或完成临床专家签审。55项依据不足都有针对精确原主张的检查记录，后续仍需补直接来源；不是把它们批量当作错误或安全。
