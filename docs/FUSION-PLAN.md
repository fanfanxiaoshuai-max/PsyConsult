## 身份与入口

个人账号注册只获得 `public`。账号密码以带独立随机盐的 scrypt 摘要保存；登录凭据使用随机会话令牌，服务端只保存其 SHA-256，8小时过期。浏览器仅在当前会话的 sessionStorage 保存访问令牌。个人登录不能调用原专业问答和知识接口。

专业身份沿用原 API_AUTH_TOKEN / API_AUTH_USERS 的绑定身份与 reader/reviewer/admin 权限。专业令牌不再写入前端构建产物；用户在专业入口输入既有令牌。当前不新增医院SSO或自动专业资质认证。专业人员也可进入自己的个人空间，两个流程分别管理。

所有资料授权在后端核验，界面隐藏按钮不是权限依据。运维或知识角色不因此自动获得其他人的个人资料。

## 数据与授权

`data/platform/platform.sqlite3` 保存账号、会话凭据、个人记录、授权、病例、专业确认记录及操作记录；原 `logs/knowledge-workbench.sqlite3` 独立保留，不迁移覆盖。上传文件以随机存储键保存在 `data/platform/uploads`，不以原文件名拼接路径。

记录类型：个人陈述、量表、报告、科普会话、临床辅助问答。自动解释与用户原话分别标记；报告提取文字、确认文字、模型解释也分别保留。

授权包含指定专业接收人、选中的记录固定快照、有效期。后续修改和新增记录不自动共享。撤销/到期后，专业端不能再读取授权快照或下载该授权文件。先前形成的专业确认记录独立保留；回传说明必须由专业人员显式确认，并在提交时仍有有效授权。这里实现资料访问关系，不自动推断委托、监护或机构关系。

接收授权时显式建立病例，不根据姓名相似度自动合并。专业端原有临时问答继续可用。病例问答由病例ID和会话ID共同派生上下文命名空间；浏览器保存的会话也按病例分开。自动回答保存为未确认问答记录，不能直接回传为专业结论。

## 公众与报告流程

公众问答独立使用科普支持流程，不调用临床诊断图。保存默认关闭；关闭时最近上下文仅用于当前问答，不写入个人记录。保存后可从个人记录继续会话。明确高风险表达走确定性提示，绕过普通模型；规则仅覆盖部分表达，不等于完整危机评估。

量表逐题完整校验、确定性计分；PHQ-9相关条目非零提示进一步评估，不直接判定危险等级。所提供中文题目为原型界面用语，正式使用前应核对目标中文版本及其适用和使用条件。

报告：上传 → 本地提取/OCR → 用户核对修正 → 显式生成解读 → 保存已有结果。自动解读会调用已配置模型服务。重复请求复用已有解读；归档不重新分析。报告修改确认文字后，旧解释保留为历史，当前解释失效。最多20MB、40页、6万字，超过限制不静默截断。处理任务采用本机双线程队列；服务重启后把处理中记录标记未完成。本版按单后端进程使用，不支持多进程分布式任务恢复。

语音：录音 → ASR → 输入框核对 → 用户发送。音频接口不持久化录音；转写服务使用独立可配置ASR端点。
