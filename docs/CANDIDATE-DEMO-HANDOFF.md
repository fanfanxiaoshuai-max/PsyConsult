# 候选知识图谱演示与专家审核交接

后续需求已改为项目内部审核和版本管理，本页保留上一阶段历史记录。当前界面和操作请以[知识审核与版本管理](PROJECT-WORKBENCH.md)为准。

验收日期：2026-10-20。交付范围：医学来源与适用范围的证据核对、本地软件验收、未签署的专家审核材料。当前版本可本地演示和提交专家审核；临床专家批准数为 0，不具备临床认证或正式上线结论。

## 使用入口

打开 http://127.0.0.1:5173/#candidate ，或点击侧栏“知识审核与版本管理”。页面入口名称已调整，实际审核状态和只读范围保持不变。

- “候选知识”：查询实体，查看带条件的修订记录、适用地区、人群、产品版本及原文定位；可切换关系预览。关系预览用于关联审核记录，不代表无条件的临床因果关系。
- “逐项审核与未解决问题”：分页查看全部 899 项，按修订、依据不足、隔离等状态筛选，查看原始记录、候选处置、补查来源和专家问题。
- “下载专家待审包”：下载全部 899 项的 JSON 包，专家姓名、结论、意见保持空白。此页面不提供批准或激活功能。
- “返回诊疗会话”：回到原有工作台。候选版没有接入诊疗推理，实际运行图谱仍是 kg_v2。

常见查询示例：抑郁症、双相情感障碍、失眠、帕罗西汀、文拉法辛、6A72。查询失眠会显示以失眠为关联对象的记录；这些记录不是治疗失眠的推荐。

## 证据核对结果及边界

全部 899 项冻结记录均纳入交接，其中 838 项涉及医学内容，61 项为结构性记录。399 项原修订已有可追溯候选处置，包含有条件替换和明确撤销；不表示全部临床结论获得批准。候选图共 406 个节点、304 条边，均不进入推理。

本轮重新核对原有来源绑定、原文定位、文件指纹、候选处置与审核包一致性，并对 55 项依据不足和 13 项隔离记录逐项记录复查结果。新增取得 5 份一手资料：NLM 提供的 4 篇作者摘要及 NICE NG10 公开建议。未取得的论文全文没有标为已阅读。此前的 21 份补查资料也在逐项详情中保留。

复查未将 68 项自动改为通过：病例报告只能提供有限风险线索，多药病例不能确定单对药物因果，药物比较试验不能证明联合用药效果，快速镇静建议不能扩大为普遍二线治疗。地区、制剂、人群、证据强度和不确定性均需专家进一步判断。

正式临床审核仍需有资质的精神科医生及药师逐项签署。对未解决事项，应补足全文或相应权威资料后再审；无法建立依据的继续停用、撤销或隔离。专家审核前不得据此激活候选图。

## 启动与重新生成

先启动 Docker Desktop，再在 PowerShell 中运行（进程级脚本执行参数，无需修改系统执行策略）：

```powershell
cd D:\PsyConsult
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run.ps1 infra
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\local-app.ps1 start
```

关闭本地前后端：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\local-app.ps1 stop
```

接口暂时不可用时，页面会显示本地服务连接提示，可在服务启动后点击“重新加载”。来源或审核包不一致会拒绝候选预览；修复来源并重新生成审核包后再加载。

维护者重新生成命令：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\fetch_expert_review_sources.py
.\.venv\Scripts\python.exe -X utf8 scripts\build_expert_review_packet.py
.\.venv\Scripts\python.exe -X utf8 scripts\verify_candidate_demo.py
```

获取资料需要联网；校验依赖本地缓存中的原始来源文件。不要修改冻结审核结果来消除阻断，也不要将模型或程序输出填写为专家签字。密钥继续保存在忽略提交的本地环境文件中，交付审核资料时不包含密钥及患者数据。
