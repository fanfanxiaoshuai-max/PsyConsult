## 主要发现及处理

- 原图谱若把类别风险警告直接写成绝对禁忌，需补查直接依据。本批有5项暂列依据不足，涉及舍曲林通用剂量范围/目标、与其他SSRI/SNRI的绝对禁忌，以及帕罗西汀与舍曲林的绝对禁忌。候选版本暂不启用这些无条件规则；这不表示联用安全。
- 剂量属性按所核对中国产品的适应症、人群和制剂拆分。特别保留“超过某剂量未系统评估”和“推荐最大剂量”的区别，没有把一个无条件数字替换为另一个无条件数字。
- MAOI换药清洗期绑定具体药物及换药方向；不作为所有抗抑郁药之间的统一换药天数。
- 氯氮平联用的美国标签内容按原地区保留为相互作用、暴露变化和监测/调整情境，不能替代尚未对照的中国批准说明书，也不能推断所有患者固定倍数变化。
- 保留“未观察到显著药代变化”与“仍有药效学风险”的区别；锂浓度方向、研究条件和监测条件逐条保存，不把类别警示自动扩成每个药物的同等风险。

以上为审计发现摘要；具体主张及其限制以`reviews.json`、`evidence.json`的逐项记录为准，不构成个体给药建议。

来源目录共14项，13项原文可用；拉莫三嗪来源本次获取失败，失败状态保留，未据此产生支持结论。原文可用与条目核对完成分别记录。
